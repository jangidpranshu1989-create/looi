# Contributing to Looi

Thanks for helping make Looi better.

1. Fork and clone, then `npm install` and `npm run dev`.
2. Keep PRs focused. Run `npx tsc --noEmit` and `npm run build` before pushing.
3. No fake data: every number Looi shows must come from a real measurement or a real API.
4. UI changes: include a before/after screenshot (desktop and mobile).
5. By contributing you agree your work is licensed under AGPL-3.0.

Good first areas: ad templates (`server/agent/render.ts`), launch playbooks (`server/agent/agent.ts`), audit checks (`server/agent/analyze.ts`), translations.
